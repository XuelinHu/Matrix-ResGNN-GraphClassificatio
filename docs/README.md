# Documentation Entry Point

Start with [PROJECT_STATUS_AND_TIMELINE.md](PROJECT_STATUS_AND_TIMELINE.md). It consolidates the current paper state, experiment milestones, submission artifacts, and reproducibility entry points.

The remaining Markdown files are retained as historical or topic-specific records:

- `WORK_PLAN.md`, `EXECUTION_MANUAL.md`, and `EXPERIMENT_CHECKLIST.md`: early planning and execution contracts.
- `FULL_BENCHMARK_QUEUE.md`: expanded benchmark queue record.
- `SYNTHETIC_DISTRIBUTION_BENCHMARK.md`: synthetic benchmark design and run notes.
- `RESULTS_SYNTHESIS.md` and `RESULT_INTERPRETATION.md`: detailed result analysis notes.
- `TODO_HANDOFF.md`: historical handoff snapshot; superseded by the consolidated status document.
- `REVIEW_AI.md`: archived external review notes.

These historical files are preserved for traceability. Use the consolidated status document as the current reading entry point.
